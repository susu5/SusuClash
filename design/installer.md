# MSI 安装界面

2026-11-16 用户确认“外圈进度 v2”静态设计并要求按该版本实现 MSI。该局部设计继承 author-v3，不修改客户端主题、动物素材或 Netfix 规则。

## 共享规范映射

原生 WinForms 界面通过 `packaging/installer/generate-theme.cjs` 从 `DESIGN.md` 的 frontmatter 和 `.impeccable/design.json` 的阴影扩展生成 `InstallerTheme.g.cs`。该文件只出现在构建工作目录。禁止在原生界面另外维护颜色表；生成器不得改变原规范和批准摘要。

字体使用现有 Windows 字体栈的 Segoe UI 与 Microsoft YaHei UI；原生控件按规范像素字号及 Windows DPI 缩放，不将12px误作12pt。小字12px、正文14px、页标题24px、对话框标题20px，卡片18px、按钮10px，外窗为直角。三主题继续使用珍珠、薄荷、夜航，安装器三主题中均保留本轮明确指定的小猫。

- 百分比及状态在圆窗下方；右侧为准备／安装／结果步骤及状态内容。
- 勾选框24px，选项行至少56px；原生勾选控件保留键盘及辅助功能语义。

## 状态与安装行为

准备页显示完整 GPL 的阅读入口、同意选项、桌面快捷方式选项和三主题选择。只有本人启动后才释放安装引擎。安装页原 GIF 持续运行，进度仅来自 MSI 工作量消息；未知工作量保留待确认，实际成功前上限99%。系统减少动态效果时使用海报，百分比仍更新。

只有本产品最终安装消息及提交后的状态回执确认成功才显示100%完成页；需要重启为独立结果，不自动重启。状态回执来自只读安装动作在有效会话中查询本次安装的重启标记，界面不保留过期会话、不解析本地化日志猜测。失败、取消、缺少最终结果或状态回执不显示成功。取消等待安装引擎的安全处理与必要回滚。文件占用只提供手动关闭后重试／取消，不自动关闭其他应用。

成功页“完成后打开 SusuClash”默认选中，仅在本人点击完成后启动既有固定入口。未成功或需重启时不启动。静默、基本／精简界面和维护操作保留原 MSI 路径；系统策略禁用嵌入界面时也使用原对话框。

安装范围、升级族、固定目录和应用数据位置沿用旧版。该界面位于 MSI 的 MsiEmbeddedUI 表，不加载进生产客户端。测试入口与模拟状态只存在于 `qa/installer/`，不进入安装载荷。
